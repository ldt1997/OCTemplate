# 开发流程

本文档描述 OCTemplate 后续新增模板和迭代模板时的推荐工作流。

## 总体原则

- 先确认需求，再写代码。
- 先搭结构，再补细节。
- 先保证预览和导出一致，再优化交互体验。
- 每一步改动都应能说明改了什么、为什么这样设计、下一步做什么。
- 如果需求会导致过早复杂化，应直接指出并给出更轻量替代方案。

## 新增模板工作流

### 1. 填写需求

使用 [新增模板需求](./new-template-requirements.md) 补齐模板信息。

必须明确：

- 模板名称和路由。
- 目标用户和核心场景。
- 桌面端和移动端布局。
- 画布尺寸。
- 图层顺序。
- 表单字段。
- 字体和图片资源。
- 导出格式和文件命名。
- 当前阶段范围。

### 2. 需求确认

开发前人工确认需求是否完整。

重点检查：

- 设计稿或图层描述是否足够实现。
- 字体是否有真实文件。
- 图片资源是否齐全。
- 导出尺寸是否固定。
- 移动端 Toolbar 如何展示。
- 是否需要图片拖拽、缩放或画布缩放。
- 哪些复杂功能可以延后。

### 3. 输出第一阶段结构方案

正式写代码前，先输出：

1. 推荐项目目录结构。
2. 第一阶段需要创建或修改的文件列表。
3. 每个文件的职责。
4. 暂不实现的复杂功能。

经过确认后再开始编码。

### 4. 搭建基础结构

优先完成：

- 新增模板资源目录。
- 新增模板 Page。
- 新增模板 Config。
- 新增 Toolbar 骨架。
- 新增 Canvas 或 Viewport 骨架。
- 接入路由。
- 接入首页模板列表。

这一阶段不追求完整视觉，只保证结构方向正确。

### 5. 实现页面 layout

完成：

- Header 导出按钮位置。
- 桌面端 Toolbar 和 Canvas 布局。
- 移动端 Toolbar 呈现方式。
- 空状态。
- 画布区域尺寸适配。

### 6. 实现核心组件

完成：

- 表单字段。
- 表单状态。
- 上传图片处理。
- 模板视觉 spec。
- 共享 layout 计算。
- 预览 canvas 绘制。

### 7. 实现导出

导出应满足：

- 使用独立 canvas。
- 使用固定导出尺寸。
- 等待字体和图片资源加载。
- 调用共享 renderer。
- 使用 `canvas.toBlob()`。
- 下载后回收 Object URL。

### 8. 验证

至少执行：

```bash
npm run build
```

如果改动包含布局或交互，还应检查：

- 桌面端主要视口。
- 移动端主要视口。
- 上传图片流程。
- 导出结果尺寸。
- 预览和导出主要元素位置是否一致。

### 9. 复盘沉淀

完成后判断是否需要更新文档。

应该更新文档的情况：

- 发现新的通用模块边界。
- 发现新的预览导出一致性规则。
- 发现新的移动端兼容策略。
- 新增模板流程中有反复出现的问题。

不应该更新项目级文档的情况：

- 只是某个模板的私有视觉细节。
- 只是一次性的资源命名。
- 只是临时 workaround。

## 小步提交建议

推荐拆分：

1. 基础结构和路由。
2. Toolbar 和默认状态。
3. Canvas 预览。
4. 资源和字体加载。
5. 导出。
6. 移动端适配。
7. 验证和清理。

如果某一步变得过大，应继续拆分。

## 临时 prompt 文件处理

当前保留：

- `docs/prompts/new-template-prompt.md`
- `docs/prompts/preview-dom-to-canvas.md`

它们的定位是历史参考和迁移来源。

后续可以删除它们，但建议满足两个条件：

1. 正式文档已经覆盖其中的长期规则。
2. 已经用正式文档完成至少一次新模板开发验证。

删除后，应以 `docs/index.md`、`docs/product-spec.md`、`docs/engineering-spec.md`、`docs/new-template-requirements.md` 和 `docs/development-workflow.md` 为唯一规范来源。

## 新增模板 checklist

需求阶段：

- [ ] 模板名称和路由已确认。
- [ ] 画布尺寸已确认。
- [ ] 图层顺序已确认。
- [ ] 表单字段已确认。
- [ ] 资源清单已确认。
- [ ] 移动端布局已确认。
- [ ] 当前阶段范围已确认。

结构阶段：

- [ ] 创建模板资源目录。
- [ ] 创建模板 Page。
- [ ] 创建模板 Config。
- [ ] 创建模板 Toolbar。
- [ ] 创建模板 Canvas 或 Preview。
- [ ] 接入路由。
- [ ] 接入首页模板列表。

实现阶段：

- [ ] 表单修改实时更新预览。
- [ ] 上传图片校验类型和大小。
- [ ] Object URL 替换和卸载时正确回收。
- [ ] 预览和导出共享 spec、layout 和 renderer。
- [ ] 字体加载完成后才允许导出。
- [ ] 导出使用固定尺寸。
- [ ] 导出使用 `toBlob()`。

验证阶段：

- [ ] 桌面端可用。
- [ ] 移动端可用。
- [ ] 导出 PNG 成功。
- [ ] 导出尺寸正确。
- [ ] 构建通过。
- [ ] 临时资源已清理。
