# 新增模板需求

新增模板前，先复制本文件中的填写表并补齐信息。Codex 应先检查信息是否完整，再输出第一阶段文件结构方案，不要直接写代码。

## 使用方式

1. 复制“需求填写表”。
2. 补齐已知信息。
3. 不确定的地方保留为空，并让 Codex 指出缺口。
4. 确认第一阶段结构方案后，再开始实现。

## 最小必填信息

- 模板名称
- 路由路径
- 核心使用场景
- 导出尺寸或尺寸来源
- 表单字段
- 图层顺序
- 图片和字体资源
- 当前阶段目标

## 填写提醒

- 导出尺寸必须有唯一来源，不能受预览缩放、屏幕尺寸或设备像素比影响。
- 如果文本可能换行，需要写清宽度、行高、对齐方式和换行规则。
- 如果字段会影响最终图片，应进入 form state，并由共享 layout 或 renderer 消费。
- 复杂交互不是默认必做项；如果不是模板核心，可以放入“可以延后”。
